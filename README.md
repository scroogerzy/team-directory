# Team Directory Command Line Tool

A simple command-line tool that displays team members.

## Features
- Display team members
- Store team information locally

## Search
The tool can search members by keyword.

## Filtering
The application can filter members by role.

updated directly from GitHub

## Running the application

Run:

python main.py

## Data

Team members are stored in `team.json` as a list of objects:

    [
      { "name": "Kaamogelo", "role": "Developer" }
    ]

Each member is a record with named fields, so new fields (email, team,
start date) can be added without changing how the file is parsed.
